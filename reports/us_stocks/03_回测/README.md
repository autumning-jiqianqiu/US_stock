## 怎么跑(要点)

1. 测试器「设置」:专家 = CrossSectionalRankEA,品种 = MCD.US-24,周期 = M30,模式 = 每笔订单基于真实点位,
   延迟 = 1 毫秒,入金 = 10000,杠杆 = 1:100,**优化 = 已禁用**。
2. **必查**:「以点数计算的盈利」不勾选;日志里应出现 `initial deposit 10000.00 USD`。
   (优化模式会把口径切成点数,结果作废 —— 因此一律用单跑。)
3. 「输入参数」→ 右键 → 加载 `sets/` 里对应的 `.set`;区间在「设置」里手动改。
4. 跑完立刻另存报告,命名放进 `报告/`。
