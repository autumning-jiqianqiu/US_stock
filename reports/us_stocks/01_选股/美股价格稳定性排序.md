# 美股价格稳定性排序 —— 筛选/收益报告

## 〇、先回答一个问题:这不是回测

`ScreenUSStocks` 是**选股脚本**,不是回测程序。它全程没有开平仓、没有持仓、没有资金曲线,
所以 CSV 里没有收益率列 —— 这是设计如此,不是漏了。

但它**确实算了收益**,只是没输出:`Sortino = (年化收益 − 无风险利率) / 年化下行波动`,
`Calmar = 年化收益 / 最大回撤`,两者内部都用到了年化收益。

反推公式:`年化收益 = Calmar × 最大回撤`。本报告第三节就是据此补出的收益列
(已写入 `reliability_ranking.csv` / `.xlsx` 的 `AnnRet_est_pct` 列)。

## 一、运行口径

| 项目 | 取值 |

| 合约口径 | 统一标准盘 `.US` |
| 分类 | 一类 = 回撤已回升 80% 且 20 日滚动回撤 ≤ 20% |

## 二、稳定性结果

**一类 36 只、二类 45 只**,全部成功计算。

| 指标（中位数） | 一类 A | 二类 B |
| --- | --- | --- |
| 综合评分 | 0.407 | −0.330 |
| 20 日滚动回撤 | 16.5% | 25.1% |
| 最大回撤 | 19.9% | 34.8% |
| Beta（对 US500） | 0.75 | 1.45 |
| 波动收敛比 | 0.83 | 0.85 |

一类的本质是**低波动 + 低贝塔的防御型标的**;波动收敛比两类几乎相同(0.83 / 0.85),
说明该维度没有区分度。

## 三、收益:反推结果（2025 全年）

### 3.1 一个必须知道的偏差

脚本的 `CalcBarsPerYear(M30)` 取 `252 × 48 = 12096` 根/年,即**按 24 小时交易**折算;
但美股现货每天只交易 6.5 小时(≈13 根 M30),一年约 `252 × 13 = 3276` 根。
两者差 `12096 / 3276 ≈ 3.69` 倍,于是:

- 年化收益被**放大 3.69 倍**
- `Calmar` 被放大 3.69 倍
- `Sortino` 被放大约 1.92 倍(= 3.69 / √3.69)

**相对排名基本不受影响**(同一标的同一系数),但**绝对数值不可直接引用**。
下文收益列已按 13 根/日 折算修正。

### 3.2 全池收益概览（修正后估算）

| 统计量 | 数值 |
| --- | --- |
| 中位年化收益 | **+19.2%** |
| 平均年化收益 | +34.1% |
| 区间 | −28.1% ~ +245.8% |
| 正收益数量 | 72 / 81 |

### 3.3 关键结论:这套排序**不选高收益**

| 对比 | 一类 A | 二类 B |
| --- | --- | --- |
| 中位年化收益 | **16.4%** | **33.4%** |
| 中位最大回撤 | 19.9% | 34.8% |

相关系数(全池 81 只):

- `评分 ~ 年化收益` = **−0.31** → 评分越高,收益反而略低
- `评分 ~ 最大回撤` = **−0.89** → 评分几乎就是"回撤规避分"
- `年化收益 ~ 最大回撤` = +0.07 → 这段样本里,**承担更大回撤并没有换来更高收益**

收益最高的 8 只几乎全在二类:

```
MU   245.8%(B, 滚动回撤 38.9%)   WBD  173.5%(B)
NEM  169.0%(B)                   LRCX 139.5%(B)
TSM  121.3%(A)  ← 唯一进一类的
KLAC  95.0%(B)                   GE    85.0%(B)
INTC  84.7%(B)
```

**所以这份排名是"稳"的排序,不是"赚"的排序。** 想提高收益,得在稳定性之外再叠加收益/动量因子。

## 四、分组看点

**4.1 统计显著的均值回归(ADF ≤ −2.86)**:`MCD · V · DE · LMT` —— 只有 4 只。

**4.2 靠低回撤入选、均值回归不显著(ADF > −1.65)**:
`RTX EW SCHW GD TJX EEM NEE F MSFT JPM BLK JNJ USB DG PNC IWM ROST ULTA GOOGL GOOG`(20 只)
——评分靠前是因为"波动小",不是"会回归"。

**4.3 低回撤组(20 日滚动回撤 ≤ 12%)**:`RTX 8.3% · KO 8.8% · MCD 9.8% · TJX 11.7% · EW 11.9%`

**4.4 高系统性风险(Beta > 1.1)**:`TSM 1.92 · IWM 1.17 · GOOGL 1.15 · GOOG 1.15`

**4.5 尾部风险最大**:`UAL 53.5% · ON 51.7% · SWKS 48.4% · NET 46.2% · ROKU 45.8%`(全在二类)

## 五、二类为什么落榜

45 只二类的中位滚动回撤 25.1%,最小值也超过 20%,整体卡在"20 日滚动回撤 ≤ 20%"这条硬门槛上。

评分仍为正的 9 只可作观察名单:
`XLE 0.274 · WFC 0.263 · WMT 0.166 · GE 0.165 · DIS 0.118 · PFE 0.088 · ISRG 0.084 · NEM 0.007 · META 0.004`

## 六、局限与风险

1. **不是回测**:无成交假设、无滑点、无手续费、无隔夜利息、无仓位管理。
2. **年化口径有 3.69 倍放大**(见 3.1),本文已修正,但脚本原值仍如此。
3. 单一样本区间(2025)、单一周期(M30),未做跨期/跨周期稳健性检验。
4. **合约口径高度敏感**:同一批标的,`.US-24` 跑 RTX 排第 35 名,`.US` 跑是第 1 名。
5. Z-score 是截面相对分,增删标的会改变所有分数。
6. Hurst 仅在 R² > 0.7 时采纳;半衰期 > 800 记 9999。
7. 14 指标 × 81 标的,未做多重检验校正,存在数据挖掘风险。

## 七、结论与建议

- **这版排序适合做低波动/防御池**,不适合当收益榜。一类中位收益(16.4%)明显低于二类(33.4%)。
- **要稳中带收益**:在一类里再叠加收益或动量筛选;可优先 `TSM`(唯一高收益且进一类)、
  `RTX / TTWO / SCHW / GD / TJX`(收益 28%~54% 且回撤可控)。
- **做均值回归**:只在 `MCD / V / DE / LMT` 上做(ADF 显著)。
- **降系统性风险**:剔除或降权一类里 Beta > 1.1 的 `TSM / IWM / GOOGL / GOOG`。
- **补一部真正的回测**:需要逐标的的分钟/小时 K 线,建议用仓库里现成的
  `ExportPepperstoneHistory.mq5` 导出 CSV,再用 Python 做含成本的策略回测。
