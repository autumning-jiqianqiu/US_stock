# 回测指南 —— MT5 策略测试器

仓库里有两个 EA,分工不同:

| EA | 类型 | 用途 |
| --- | --- | --- |
| `CrossSectionalRankEA.mq5` | **截面打分 + 定期调仓** | 主推。把选股逻辑真正做成组合策略 |
| `MeanReversionEA.mq5` | 单品种择时 | 辅助。对单只标的做 z-score 高抛低吸 |

---

## 一、CrossSectionalRankEA(主推)

### 逻辑

选股脚本给的是**横截面排序**,所以回测也必须是横截面组合:

```
每个调仓日:
  1) 对每只标的,只用「过去 InpLookbackBars 根 K 线」重算评分
     —— 绝不使用未来数据
  2) 各维度截面 Z-score → 加权总分
  3) 按总分降序取前 InpTopN 名
  4) 等权(或按分数加权)持有,单标的不超过 InpMaxWeightPct
  5) 调出的平仓、新进的建仓、偏离超过容差的再平衡
持有到下一个调仓日,重复
```

参与打分的维度(与选股脚本同源,但去掉了 Hurst 与 ADF 高阶滞后项):

| 维度 | 指标 | 权重 |
| --- | --- | --- |
| 均值回归 | ADF t 值(半衰期回归的 t)、半衰期 | 0.25 |
| 回撤 | 最大回撤、回升所需根数 | 0.15 |
| 滚动回撤 | 20 日窗口最差回撤 | 0.30 |
| 波动收敛 | 近期波动 / 全窗波动 | 0.05 |
| 收益效率 | Sortino、Calmar | 0.10 |
| 系统性 | Beta 偏离 1 的程度 | 0.05 |

「一类」硬过滤(回升 ≥80% 且 20 日滚动回撤 ≤ 阈值)由 `InpOnlyClassA` 控制。

### 主要参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `InpSymbols` | 空 | 逗号分隔;留空=当前图表品种。组合回测请填一类代码 |
| `InpBenchmark` | US500 | 算 Beta 的基准,会自动匹配同义名 |
| `InpTF` | M30 | 数据周期 |
| `InpRebalanceDays` | 21 | 调仓间隔(日历天),21 ≈ 每月 |
| `InpTopN` | 8 | 持有评分最高的 N 只 |
| `InpWeightMode` | 0 | 0=等权,1=按分数加权 |
| `InpMaxWeightPct` | 25 | 单标的权重上限 |
| `InpLookbackBars` | 1500 | 评分回看 K 线数(M30 约 115 个交易日) |
| `InpMinBars` | 300 | 少于这么多根不参与 |
| `InpOnlyClassA` | true | 只买一类 |
| `InpRollingDays` / `InpRollingThresh` | 20 / 0.20 | 滚动回撤窗口与阈值 |
| `InpAdjustTolPct` | 30 | 目标手数偏离超此%才调整(省成本) |

### 怎么跑

1. MetaEditor 编译 `CrossSectionalRankEA.mq5`(`Fn+F7`)。
2. MT5 按 `Ctrl+R` → 专家顾问选 `CrossSectionalRankEA` → 周期 M30 →
   日期 `2025.01.01 ~ 2025.12.31` → 模型「每一分钟 OHLC」。
3. `InpSymbols` 填入一类代码,例如:
   ```
   RTX.US,TSM.US,MCD.US,KO.US,V.US,TTWO.US,EW.US,SCHW.US,DE.US,MMM.US,MA.US,XOM.US,GD.US,ZM.US,TJX.US,LMT.US,BKNG.US,EEM.US,NEE.US,PEP.US
   ```
   (至少 15~20 只才有多样性;太少时 TopN 没得挑。)
4. 「交易品种」随便选一只(如 `RTX.US`),因为它只决定 tick 时间轴。
5. 点开始。日志会每次调仓打印「有效/一类/滚动回撤/分数/目标权重」全表。

### 注意

- **首次运行要下载历史**,列表里品种越多、回看越长,准备时间越久。
- 只用「过去」窗口评分,所以回测前期(不足 `InpLookbackBars`)不会建仓。
- **只做多**,不做空。
- 评分是**简化版**:不含 Hurst、不含 ADF 滞后项、不含连续下跌类指标。
  要 100% 复刻选股脚本的评分,需要把选股脚本的指标函数抽成公共 `.mqh` 再共用。

## 二、MeanReversionEA(辅助)

单品种 z-score 均值回归:`z ≤ 入场阈值` 买入,`z ≥ 出场阈值` / 回到均值 / 超时 / ATR 止损离场;
仓位按单笔风险 % 计算。参数与说明见 EA 顶部注释。

它不是组合策略,**不参与截面排序**,适合用来单独研究某只标的的均值回归特性。

---

## 三、两版都要注意的坑

1. **隔夜利息**:美股 CFD 多头要付融资成本,持仓越久越贵。调仓越频繁,成本越高。
2. **点差**:美股 CFD 点差比大盘股宽,TopN 轮换会产生实打实的换手成本。
3. **合约口径**:`.US` 与 `.US-24` 是两套报价,选股/回测必须统一。
4. **数据长度**:测试器只下载"用到的"历史;品种列表里有历史不全的会被跳过,务必看日志。
5. **幸存者偏差**:选股池是"今天还活着且走势平稳"的标的。
6. **样本外**:2025 调参就别用 2025 验证,至少换 2024 或 2026 上半段。
7. **对照基准**:和"等权持有同一批标的、期间不动"比较 —— 跑不赢躺着不动就没有 alpha。
