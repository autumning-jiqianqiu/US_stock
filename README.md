# 美股选股策略 (US Stock Selection Strategy)

一个跑在 MetaTrader 5 上的美股选股策略:先用基本面把质量差的股票筛掉,再按近期涨幅排名,
买入前 8 名、等权持有,每 21 天换一次仓。只做多,不加杠杆。

> 版本 v2.10 ｜ 回测环境:MT5 策略测试器 + Pepperstone 模拟账户 ｜ 仅供研究,不构成投资建议

## 策略怎么跑

一共四步:

| 步骤 | 做什么 |
|---|---|
| 1 选池子 | 从 81 只美股/ETF 里,用基本面指标筛掉质量差的,留下 53~55 只 |
| 2 分类 | 用历史数据判断每只股票"跌得深不深、亏了能不能涨回来",分成一类和二类 |
| 3 排序 | 按近期涨幅排名(看最近 1500 根 K 线),涨得好的排前面 |
| 4 买入 | 优先买一类的前 8 名,不够就用二类补;等权分配,每 21 天重算一次 |

两条原则:所有指标只看历史数据、不看未来;财报只用当时已经公布过的。

## 快速开始

### 1. 编译 EA

把 `mql5/Experts/US/CrossSectionalRankEA.mq5` 复制到 MT5 数据目录的 `MQL5/Experts/US/`,
在 MetaEditor 里按 F7 编译,应显示 `0 errors, 0 warnings`。

### 2. 更新基本面数据(每季度一次)

```bash
python3 scripts/us_stocks/fetch_fundamentals.py --asof YYYY-MM-DD
```

脚本会从 SEC 官网拉取财报,生成数据文件并复制到 MT5 的 `Common\Files`。
注意:文件里预留的联系邮箱是占位符,请换成你自己的邮箱再运行。

### 3. 回测设置(必查项)

- 专家 = `CrossSectionalRankEA`,品种 = `MCD.US-24`,周期 = `M30`
- 模式 = 每笔订单基于真实点位,延迟 = 1 毫秒,入金 = 10000,杠杆 = 1:100
- **优化 = 已禁用**;**"以点数计算的盈利"必须不勾选**(勾了盈亏会放大 100 倍,账户必爆仓)
- 日志里应出现 `initial deposit 10000.00 USD`
- 区间:2025.01.01–2025.12.31 或 2026.07.01–2026.10.08

### 4. 加载参数集

参数集在 `reports/us_stocks/03_回测/sets/`,先复制到 MT5 的 `MQL5\Profiles\Tester\`,
再在"输入参数"标签右键 → 加载。文件名对应关系:
`US_2025_mom`(2025 纯涨幅)、`US_2025_hyb`(2025 混合)、`US_2025_bench`(2025 基准)、
`US_2026H2_*`(样本外)、`US_*_21d|42d|63d_(fill|cash)`(不同换仓周期)、`US_gate*`(大盘保护)。

## 回测结果

| 区间 | 纯涨幅排序 | 混合排序 | 同池等权(对照) |
|---|---:|---:|---:|
| 2025 全年(53 只,21 天换仓) | +26.08% | +21.97% | +16.22% |
| 2026.07–10 样本外(55 只) | −2.99% | −3.10% | −0.13% |

换 4 个不同的起点各测一年:**2 次跑赢、2 次跑输**,其中覆盖 2026 年的两次都跑输。

### 主要结论

- **换仓周期影响最大**:21 / 42 / 63 天的结果是 +26.08% / +9.94% / +21.05%,42 天那档反而跑输。
- **加入基本面质量分是负贡献**(两次区间一致),建议默认只用涨幅排序。
- **大盘保护有用但不够**:2025 年最大回撤从 22.18% 降到 13.42%,夏普从 2.11 升到 2.79;2026 年能少亏,但没能翻盘。
- **扩大股票池明显变差**(−7.68pp),已改回小池。
- **"一类不够时用二类补"是唯一稳定有效的改动**(+6.87pp)。
- 成本主要来自持仓利息(约每年 6.5%),手续费可以忽略。
- 当前最优配置:**53 只小池 + 纯涨幅排序 + 大盘保护**。在解决换仓周期问题之前,不再调参数。

## 风险与局限

样本外只有 3 个月、5 次换仓,样本太少;股票池只有 53~55 只,增删几只就会影响全部排名;
没有模拟滑点;财报是一个季度前的数据,也没有做行业中性化;指标数量多但没做多重检验校正,
存在数据挖掘风险。详细分析见 `reports/us_stocks/04_工作报告/`。
